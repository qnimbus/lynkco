# Security Policy

## Supported Versions

Only the most recent public version is supported, excluding prereleases. No updates will be provided to previous versions of this integration, and users are expected to use the latest version at all times.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub: open the [Security tab](https://github.com/qnimbus/lynkco/security) of this repository and choose **Report a vulnerability**. Do not open a public issue for security problems.
